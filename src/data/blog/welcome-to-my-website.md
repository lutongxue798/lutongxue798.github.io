# 欢迎来到我的个人网站！

很高兴你能够找到这里！这是我用 [Astro](https://astro.build/) 和 [AstroPaper](https://github.com/satnaing/astro-paper) 主题搭建的个人网站。

## 关于这个网站

这个网站主要用于：

- 📝 分享我的技术思考和学习笔记
- 🎨 展示我的个人项目和作品
- 💭 记录生活中的点点滴滴
- 🔗 分持有价值的资源和链接

## 网站特点

- ✨ 极简设计，专注于内容阅读
- 🌓 支持明暗模式切换
- 📱 完美适配移动设备
- ⚡ 极速加载，优化用户体验
- 🔍 内置搜索功能，方便查找文章

## 持续更新中

网站刚刚搭建完成，很多内容还在不断完善中。如果你有任何建议或想法，欢迎通过 [关于我](/about) 页面中的联系方式与我交流！

感谢你的访问，希望你能在这里找到有价值的内容！
